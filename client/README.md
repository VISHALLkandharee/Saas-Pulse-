# Client — SaaS Pulse (Next.js frontend)

This is the Next.js client for SaaS Pulse. For the full project overview, API docs, and demo link, see the root README: https://github.com/VISHALLkandharee/Saas-Pulse-/blob/docs/readme-polish/README.md

Quick start
1. cd client
2. npm install
3. cp .env.local.example .env.local
4. npm run dev

Live demo (full app): https://saas-pulse-liart.vercel.app/

If you need to run only the client against a local backend, set NEXT_PUBLIC_API_URL and NEXT_PUBLIC_SOCKET_URL in .env.local to your backend address (e.g., http://localhost:4000).
